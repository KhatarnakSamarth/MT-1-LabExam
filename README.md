# Vehicle Management Web Application
- **Full Stack Development –** Node.js Lab Examination
- **Technology:** Node.js, HTTP Module, FS Module, Express.js
- **Database:** Not Required (Use JavaScript Array)

## Problem Statement
Develop a Vehicle Management Web Application to maintain vehicle records using Node.js and
Express.js.
The application must demonstrate the working of the Node.js HTTP module, routing, handling
different HTTP methods, serving static files using the FS module and implementing REST APIs using
the Express.js framework.
You are required to implement the application in separate modules as described below.
